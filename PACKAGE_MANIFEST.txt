This is a source package. Do not commit generated dist/ or node_modules/; Vercel runs npm run build from the project root. The command runs the dependency-free root-level build.mjs, which copies eligible HTML pages while preserving nested paths, copies required assets, validates the blog outputs and generates the sitemap/robots files.

build.mjs is the production build command. It copies eligible source HTML files while preserving their relative paths, copies shared assets and public files, verifies the blog listing, article and images, then scans the built HTML and synchronizes sitemap.xml and robots.txt at the root, under public/, and in dist/. Vite is retained for local development only.

The sitemap URL remains https://www.reconbrief.in/sitemap.xml. www is the preferred host because production redirects non-www requests to www.

Eligible HTML page files are discovered automatically by build.mjs and copied with their relative paths preserved. index.html.html and common private, test, preview, draft, redirect, and error-page filenames are excluded. The sitemap further requires a self-canonical HTTPS URL on www.reconbrief.in, excludes noindex pages and private/test routes, excludes Vercel-configured redirect sources, and requires the canonical path to match the built HTML route.
